How it works

  1. Report. Students and Staff report what they lost or found. Found items go to the security desk.
  2. Search. Search the items held at the security desk.
  3. Claim. Say what makes the item yours. The security officer checks your answers against private details only the owner would know.
  4. Collect. Collect the item with your ID. Every hand-back is recorded.

Security officers: use the Security desk log-in.
